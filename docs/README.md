# Diagramas do Scores: American Football — índice

Uma pasta por requisito: `RF1/` … `RF66/` (funcionais; RF1–RF59 com o mesmo número e função do Scores de basquete, D-2; RF60–RF66 só do futebol americano) e `RNF1/` … `RNF13/` (não funcionais). Cada pasta tem os 5 diagramas — atividades (`act`), sequência (`seq`), componentes (`cmp`), classes (`cls`) e máquina de estados (`stm`) — em `.puml` (fonte) e `.svg`, e um `README.md` com a história de usuário, os endpoints e os pontos de decisão.

Gerados por `generator/generate.py` a partir de `generator/model/*.py` (fonte única, D-7) e do catálogo `generator/common.py`. Nunca edite os `.puml` à mão: mude o modelo e rode `python3 generator/generate.py`, depois renderize com o PlantUML (`java -jar plantuml.jar -tsvg RF*/*.puml RNF*/*.puml`). Endpoints ainda sem controller aparecem como ⛔ alvo; `generator/endpoints_code.json` lista os que já existem no `scores-af-web`.
